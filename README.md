# Concord: downloads

Instaladores do aplicativo de desktop do **Concord**, um chat de texto, voz e vídeo para um
grupo fechado de amigos.

O Concord é privado e funciona só com convite. Este repositório existe apenas para
hospedar os instaladores.

## Baixar

Pegue a versão mais recente na página de [Releases](../../releases/latest):

| Sistema | Arquivo |
| --- | --- |
| Windows | `Concord-win.exe` |
| Linux (qualquer distribuição) | `Concord-linux.AppImage` |
| Ubuntu / Debian | `Concord-linux.deb` |

Também dá para usar direto no navegador ou instalar como aplicativo pelo próprio navegador
(Chrome ou Edge).

## Windows: aviso do SmartScreen

Como o instalador não é assinado digitalmente, o Windows pode mostrar
"O Windows protegeu seu PC". Clique em **Mais informações** e depois em
**Executar assim mesmo**.

## Linux

```bash
chmod +x Concord-linux.AppImage
./Concord-linux.AppImage
```

## Dúvidas

Fale com quem te convidou para o Concord.
